Embedded SQLite with global consensus replication.

Kite turns in-process SQLite databases into a distributed, multi-master cluster. Writes commit locally in sub-millisecond time and stream over Raft consensus to your replica network.

$ curl -fsSL https://kite.sh/install | sh

Storage Engine

  • Zero-Copy WAL Tailing I/O

    Direct memory-mapped streaming of SQLite Write-Ahead Logs without user-space roundtrips.

  • Deterministic Virtual Machine VFS

    Custom Virtual File System (VFS) guaranteeing identical page states across arm64 and x86_64 nodes.

  • Atomic 5-Second Rollbacks Safety

    Pre-flight transaction verification ensures zero corrupted pages if a leader abruptly disconnects.

Replication Topology

  • Lightweight Raft Consensus Consensus

    Optimized 3-node leader election with 250ms heartbeat intervals and automatic split-brain resolution.

  • Encrypted P2P WireGuard Network

    Direct peer-to-peer tunnels without intermediary brokers. Keys are negotiated via hardware enclaves.

  • Zero Infrastructure Markup Sovereignty

    Runs cleanly on any commodity $4/mo virtual server with predictable memory bounds under 64MB.
